Privacy Policy — Daily Shorts

Last updated: 12 October 2026

Who uses this app

Daily Shorts is a personal tool used only by the owner of the YouTube channel Randomranks, on their own computer.

What Google data it uses

  • Upload videos (YouTube scope youtube.upload): to post the day's Short to the owner's own channel.
  • Read public YouTube data (scope youtube.readonly): to search which public cooking Shorts are popular, as inspiration for new, original videos.

How data is stored and shared

The sign-in token is stored only on the owner's computer. No Google user data is sold, shared with third parties, or used for advertising. No data from any other person's account is accessed.

Use of Google user data

Daily Shorts' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
